# تحليل صرف الأدوية (v6)

نسخة تجريبية مستقلة لتحليل ملفات الصرف (مجاني / مدعم).

## التشغيل
افتح `index.html` في المتصفح أو Spck Editor.

## التحديث الأخير
- رسم حركة الصنف اليومي: **أعمدة** بدل النقاط، مع tooltip (كمية + نسبة)
- باريتو: اضغط الكارت للإظهار، واضغط تاني للإخفاء
- علامة × في شريط البحث: لون أحمر واضح
