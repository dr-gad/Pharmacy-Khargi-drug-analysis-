# تحليل صرف الأدوية – نسخة تجريبية مستقلة

مشروع تجريبي منفصل تماماً عن التطبيق الأساسي (صيدلية الخارجي).

## الهدف
اختبار فكرة تجميع وتحليل بيانات صرف الأدوية من ملفات Excel اليومية والشهرية قبل دمجها في المشروع الرسمي.

## المميزات الحالية
- تبويبان: **مجاني** | **مدعم**
- رفع ملف يومي (يوم محدد) أو ملف شهري كامل
- الملف الشهري يستبدل أي بيانات يومية سابقة لنفس الشهر
- إمكانية حذف بيانات يوم أو شهر كامل
- عرض حالة الرفع (أيام مرفوعة / غير مرفوعة)
- تحليل:
  - أكثر 20 صنفاً (شهر) أو أكثر 10 أصناف (يوم)
  - رسم بياني لباقي الأصناف
  - جدول تفصيلي مع النسب
  - فلترة حسب صنف معين
- التخزين: **IndexedDB** (محلي في المتصفح)

## طريقة التشغيل
1. افتح ملف `index.html` مباشرة في المتصفح (Chrome / Edge مفضّل).
2. أو شغّل خادماً محلياً بسيطاً:
   ```bash
   npx serve .
   ```
3. ارفع ملفات Excel الحقيقية (اليومية أو الشهرية) وجرّب التحليل.

## هيكل ملفات Excel المدعومة

### الملف اليومي
- ورقة `منصرف روشتات`:
  - الكود | اسم الصنف | الكمية | رقم الروشتة | اليوم | الشهر

### الملف الشهري
- ورقة `جميع الأصناف`:
  - كود | اسم الصنف | 1 | 2 | … | 31 | Total

## الخطوات التالية (بعد الاستقرار)
- نقل المنطق إلى المشروع الأساسي
- استبدال IndexedDB بـ Turso للمزامنة بين الأجهزة
- دعم آخر 12 شهراً
- تحسينات واجهة إضافية حسب الملاحظات
